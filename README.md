# LessonLens

LessonLens is a frontend-only hackathon prototype for government school teachers. A teacher can paste a short classroom transcript, run a mock analysis, and receive supportive teaching feedback.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- React

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Prototype Notes

- Uses mock feedback from `lib/mockFeedback.ts`
- Uses a sample classroom transcript from `lib/sampleTranscript.ts`
- No API calls, authentication, database, audio upload, PDF export, or multilingual support
